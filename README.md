# NudeNote – Responsive Landing Page

A modern, clean, and responsive landing page built using HTML, CSS, and JavaScript.

## Features

- Responsive design for desktop, tablet, and mobile
- Navigation menu with mobile support
- Call-to-action buttons
- Smooth animations and scroll effects
- Interactive task management
- Daily habit tracker
- Notes section with browser storage
- Progress dashboard

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
